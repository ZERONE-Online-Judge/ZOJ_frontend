# ZOJ 카드 디자인 기준

공개 페이지, 참가자 화면, 운영자·서비스 관리자 화면은 `src/styles/design-tokens.css`의 색상과 크기를 함께 사용합니다.

- 묶음은 옅은 배경과 얇은 테두리로, 입력창과 내부 선택지는 흰색으로 구분합니다.
- 제목 → 설명 → 입력·선택 → 적용 안내 순서로 배치합니다. 설명과 안내는 본문보다 작고 옅게 표시합니다.
- `ManagementPanel`은 운영 화면의 묶음, `SettingsCard`는 설정 그룹, `ChoiceCard`는 라디오·체크박스 선택지에 사용합니다. 모두 `src/components/common/ManagementCards.tsx`에서 가져옵니다.
- 일반 콘텐츠 카드는 `zoj-card`, 내부 흰색 영역은 `zoj-inset`을 사용합니다. 기존 공개 페이지의 고유 레이아웃은 같은 디자인 토큰을 참조합니다.
- 선택지는 카드 전체를 누를 수 있게 하고, 기본 HTML 입력 요소의 키보드 조작·포커스·비활성 상태를 유지합니다.
- 카드의 모서리·테두리·배경·강조색을 페이지별 숫자로 다시 정의하지 않습니다. 반응형 배치는 카드 내부 너비를 기준으로 확인합니다.
- 채점 결과와 오류·주의 색상은 의미를 유지합니다. 메인·소개 배너의 일러스트와 애니메이션, 발표용 프레젠테이션의 전용 구성은 별도로 유지합니다.

## 모달

- 안내·확인, 제출·문제 조회, 계정·알림 패널은 `src/shared/ui/ModalDialog.tsx`의 `ModalDialog`와 `ModalButton`을 사용합니다. 모달별 테두리·제목·닫기 버튼을 다시 만들지 않습니다.
- 제목 영역과 하단 동작 영역은 옅은 배경, 본문은 흰색입니다. 닫기는 오른쪽 위에 두고, 하단은 취소 → 주요 동작 순서로 배치합니다. 삭제에는 `danger`, 적용에는 `primary`를 사용합니다.
- 짧은 안내는 기본 `sm`, 팀 정보는 `md`, 파일·계산 내역은 `lg`, 표·문제는 `xl`, 편집기와 제출 상세는 `wide`를 사용합니다. 긴 조회 화면은 `fill`로 높이를 확보합니다.
- 기본 본문만 스크롤됩니다. 표·코드·분할 편집기는 `customBody`를 사용하고 내부 스크롤 영역에 `min-height: 0`과 적절한 `overflow`를 지정합니다. 제목·하단 버튼은 본문 스크롤 밖에 둡니다.
- `title`은 필수입니다. 별도의 접근 가능한 이름이 필요하면 `aria-label`을 사용합니다. `description`은 자동으로 대화상자 설명과 연결됩니다.
- 업로드 진행·세션 만료처럼 선택이 필요한 창은 `onClose`를 생략합니다. 닫기 버튼·Escape·배경 클릭으로 빠져나갈 수 없으므로, 작업 완료 또는 하단 동작으로 종료해야 합니다.
- `Modal`은 포커스 복귀, 중첩 모달과 배경 스크롤 잠금을 담당합니다. 개별 화면에서 이를 중복 구현하지 않습니다. 모바일 세로·가로 화면, 긴 제목·본문, 키보드 조작, 동작 줄이기 설정을 확인합니다.
